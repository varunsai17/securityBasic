QQQ) Do I Need to Explicitly Store Roles and Authorities as (Role_User , Role_Admin) or (user , admin) is enought?
A) No, User and Admin is enough,Because look at the below code of MyCustomUserDetailsServiceClass
---------------------------------------------------------------------------------------
UserDetails userDetails = org.springframework.security.core.userdetails.User.builder()
                .username(user.getUserId())
                .password(user.getPassword())
                .roles(user.getRole())
                .build();
----------------------------------------------------------------------------------------
In the below class even thought user.getRole() is admin ,It is stored in userDetails object as Role_admin so you
don't need to explicitly mention it as a role.
